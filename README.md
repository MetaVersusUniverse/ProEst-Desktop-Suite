## 📖 Overview

**EstimForge 2026** is a complete desktop workspace for construction cost modeling, quantity surveying, and project budgeting. Where spreadsheets bend and break under the weight of a real project, EstimForge holds its shape — like a steel frame around your numbers. It is designed for contractors, estimators, architects, and small-to-medium construction firms who want a serious, offline-capable desktop application on Windows 10 and Windows 11.

This repository hosts the official distribution, documentation, release notes, and issue tracker for EstimForge 2026. The application itself installs locally and runs without a subscription gate on everyday tasks, giving you a dependable digital drafting table for estimate building.

> EstimForge 2026 is an independent project inspired by the broader category of professional estimating tools, and it is not affiliated with any third-party vendor.

## ✨ Feature Highlights

### 🖥️ Responsive Desktop UI
The interface adapts gracefully from a compact laptop screen to a multi-monitor estimator's battle station. Panels snap, dock, and resize without losing your place. A responsive UI in this context isn't about phones — it's about respecting every pixel you paid for.

### 🌐 Multilingual Support
A multilingual work environment means your Indonesian foreman, your Spanish-speaking subcontractor, and your German client can all read the same estimate without a translator. Twelve languages ship in 2026, with number and currency formatting handled natively.

### 📊 Line-Item Cost Modeling
Break a building into assemblies, sub-assemblies, and granular items. Assign materials, labor hours, equipment rates, and overheads. EstimForge rolls everything up to a project total instantly, and it never loses the trail back to the source value.

### 🧮 Quantity Takeoff Assistant
Measure areas, volumes, and linear runs through guided workflows. The takeoff assistant helps you convert dimensions into quantities with less manual arithmetic and fewer keystrokes.

### 💾 Offline-First Architecture
Your project data is stored on your machine. No internet connection is required for day-to-day estimating. When cloud sync is available, it is optional — not mandatory.

### 🕐 24/7 Customer Support
Questions don't keep office hours, and neither does our support channel. Around-the-clock assistance is available for license and setup questions, so a deadline at midnight never becomes a dead end.

### 🔐 Data Integrity Toolkit
Automatic rolling backups, checksum verification of project files, and a metadata inspector that tells you exactly which build produced a given estimate.

### 🧩 Report Builder
Generate professional PDF and print-ready summaries with configurable columns, logos, and footnotes. The report builder was built for people who still hand a stack of paper to a project owner.

### 🧠 Smart Templates
Reusable template libraries for residential, commercial, and civil categories. Start from a known shape and modify it — faster than a blank page, safer than a copy-paste from a stale spreadsheet.

### ⚙️ Automation Rules
Define rules for markup application, unit conversion, and rounding. EstimForge follows your house rules consistently, removing the "which version of the formula did we use?" debate.

### 📁 Project Hierarchy
Organize projects, phases, and versions in a clear tree. Compare version A to version B and see a diff of every changed line item.

### 🗃️ Import and Export Bridges
Bring in CSV, Excel-compatible tables, and structured data from other estimating packages. Export to spreadsheets for accounting, or to structured files for archival.

### 🎨 Theme and Accessibility
Dark, light, and high-contrast themes. Adjustable font scaling. Estimators who stare at numbers for eight hours deserve an interface that is kind to their eyes.

### ⌨️ Extensive Keyboard Shortcuts
Power users can navigate, edit, and calculate without lifting hands from the keyboard for most daily operations.

## 🚀 Getting Started

Setting up EstimForge on a Windows 10 or Windows 11 machine is designed to be a straightforward desktop experience. The distribution arrives as a local installer that walks through component selection, default workspace location, and interface language.

**A typical onboarding flow:**

1. **Prepare your environment.** Confirm your Windows build is current and that you have at least a few gigabytes of disk space available for project files and backups.
2. **Obtain the installer package.** Use the distribution reference provided at the top and bottom of this document.
3. **Run the local setup wizard.** Choose your installation directory, default units, and the languages you want enabled.
4. **Launch EstimForge.** The first-run assistant will offer to load a sample project so you can explore the interface with real-looking data.
5. **Create your first project.** Name it, pick a category template, and begin adding line items.
6. **Define your rate tables.** Enter material, labor, and equipment rates once, then reference them across projects.
7. **Build an estimate.** Add items, assign quantities, and watch totals roll up in real time.
8. **Generate a report.** Export a PDF or print preview for review.

## ⚙️ Configuration and Settings

EstimForge stores preferences in a human-readable configuration file within your user profile. You can back it up, move it between machines, and version-control it if you like.

**Key settings you can adjust:**

- `default_currency` — Set the currency symbol and formatting style.
- `unit_system` — Metric, imperial, or mixed.
- `interface_language` — Choose from the multilingual set.
- `theme` — Light, dark, or high-contrast.
- `backup_interval` — How often automatic rolling backups occur.
- `report_branding` — Logo, footer text, and page numbering.
- `numeric_precision` — Decimal places for quantity and cost columns.

A settings import/export panel lets you clone your environment to a colleague's workstation in seconds.

## 🔄 Workflow Walkthrough

### Phase 1 — Project Intake
Create a project shell, assign a client, and set the estimate date. EstimForge timestamps everything for the audit trail.

### Phase 2 — Takeoff
Enter dimensions and counts. The takeoff assistant helps translate geometry into quantities without a separate calculator.

### Phase 3 — Pricing
Attach rates from your tables. Apply markup rules. EstimForge recalculates instantly, and every change is logged.

### Phase 4 — Review
Switch to comparison view to see current estimate versus baseline. Diffs are highlighted, and you can annotate reasons for each change.

### Phase 5 — Output
Generate reports, export for accounting, or archive the project with a versioned snapshot.

### Phase 6 — Archive
Completed projects live in a searchable local index. Find an old estimate by client name, date, or keyword.

## ❓ Frequently Asked Questions

**Is EstimForge a web service?**
No. It is a desktop-first application for Windows 10 and Windows 11.

**Do I need an internet connection to use it?**
For day-to-day estimating, no. Some optional features may require connectivity.

**Can I move my projects between machines?**
Yes. Project files are portable, and the settings export panel makes migration simple.

**Does it handle multiple currencies in one project?**
Yes. You can assign a base currency per project and secondary currencies per rate table.

**How often are backups created?**
By default, every fifteen minutes of active editing. You can change this in settings.

**Is there a way to try before committing?**
A sample project ships with the installer so you can explore the interface immediately.

## 🛠️ Troubleshooting

**The installer stops partway through.**
Check available disk space and antivirus quarantine logs. Windows sometimes flags new installers during the first days of distribution.

**My totals look wrong.**
Open the item inspector and check the unit and rounding settings for that line item. EstimForge will show you the exact arithmetic.

**A report exports with odd characters.**
Verify the locale settings for the project and the report font. Some fonts lack glyphs for certain currencies.

**The interface feels slow on large projects.**
Reduce visible columns in the grid, or split very large projects into phases.

**I forgot my settings configuration.**
EstimForge keeps the last three configuration snapshots. Restore from the settings panel.
